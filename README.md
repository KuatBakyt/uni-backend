# University Backend

Ранний учебный проект на Django REST Framework: сущности университета — факультеты, студенты, курсы и новости.

## Структура

- `faculty/` — факультеты.
- `students/` — студенты.
- `courses/` — курсы.
- `news/` — новости.
- `university_backend/` — настройки и маршруты.

## Статус

Учебный прототип. Файлы tests.py пока содержат стандартные заглушки, воспроизводимый запуск с закреплёнными зависимостями не подготовлен. Не использовать как production-сервис: настройки доступа и безопасности требуют отдельной доработки.

Локальная SQLite-база и Python-кеш исключены из текущей версии репозитория. Ранее закоммиченные файлы остаются в истории Git; её переписывание не выполнялось.

Основной актуальный backend-проект: [Flowza CRM](https://github.com/KuatBakyt/flowza-crm).
